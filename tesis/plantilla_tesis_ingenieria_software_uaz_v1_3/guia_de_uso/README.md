# Ejemplos de uso de LaTeX

El archivo `ejemplos_latex.tex` contiene bloques listos para copiar en los
capítulos de la tesis. No se incluye automáticamente en `main.tex` y, por tanto,
no agrega páginas al documento.

Si es su primer proyecto en LaTeX, empiece por el `README.md` de la carpeta raíz.
Ahí encontrará instrucciones para importar el ZIP en Overleaf, identificar los
archivos que debe editar, seleccionar una estrategia de evaluación y resolver
errores comunes. El mes y el año de la portada interior se actualizan con la
fecha de compilación.

Antes de entregar la versión final:

1. Cambie `\mostrarInstruccionestrue` por `\mostrarInstruccionesfalse`.
2. Cambie `\mostrarEjemplostrue` por `\mostrarEjemplosfalse`.
3. Sustituya los archivos, textos, títulos y etiquetas utilizados como ejemplo.
4. Compile nuevamente para actualizar referencias e índices.
